Lab: Getting Started with Snowflake and Snowsight

Exercise

Answer all five questions by writing your own queries in your SQL file against SNOWFLAKE_SAMPLE_DATA.TPCH_SF1. Use the patterns from Step 5; no new syntax is required.

Task 1 - Customers by market segment

Using the CUSTOMER table, write a query that returns the number of customers in each market segment (C_MKTSEGMENT), ordered from the largest segment to the smallest.

Task 2 - Orders by order priority

Using the ORDERS table, write a query that returns the number of orders for each O_ORDERPRIORITY value, ordered from most orders to fewest.

Task 3 - Nations in a region

Using the NATION and REGION tables, write a query that returns the names of all nations (N_NAME) in the region named ASIA. Join the two tables on the region key (N_REGIONKEY = R_REGIONKEY).

Task 4 - Total spend by market segment

Using the CUSTOMER and ORDERS tables, write a query that returns the total order value (O_TOTALPRICE) for each market segment (C_MKTSEGMENT), rounded to whole numbers, ordered from highest total to lowest. Join the two tables on the customer key.

Task 5 - Highest value orders for a single segment

Using the CUSTOMER and ORDERS tables, write a query that returns the ten highest value orders placed by customers in the AUTOMOBILE market segment. Show the customer name, the order date, and the order total, with the largest order total first.

Solutions

Each solution below fully qualifies table names, so the queries run regardless of which database and schema are selected in the context selector. A running warehouse such as INTRO_WH is required for all of them.

Task 1 - Customers by market segment

SELECT
    C_MKTSEGMENT,
    COUNT(*) AS CUSTOMER_COUNT
FROM SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.CUSTOMER
GROUP BY C_MKTSEGMENT
ORDER BY CUSTOMER_COUNT DESC;

What you should see: Five rows, one per market segment (AUTOMOBILE, BUILDING, FURNITURE, HOUSEHOLD, MACHINERY). The 150,000 customers are distributed fairly evenly, so each segment holds roughly 30,000 customers. The exact counts differ slightly between segments, which is why the ORDER BY is needed to rank them.

Task 2 - Orders by order priority

SELECT
    O_ORDERPRIORITY,
    COUNT(*) AS ORDER_COUNT
FROM SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.ORDERS
GROUP BY O_ORDERPRIORITY
ORDER BY ORDER_COUNT DESC;

What you should see: Five rows, one per priority level (1-URGENT, 2-HIGH, 3-MEDIUM, 4-NOT SPECIFIED, 5-LOW). The 1,500,000 orders are spread fairly evenly across the five priorities, so each count is near 300,000. This mirrors the row-count and grouping pattern from Step 5, applied to a different column.

Task 3 - Nations in a region

SELECT
    n.N_NAME
FROM SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.NATION n
JOIN SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.REGION r
    ON n.N_REGIONKEY = r.R_REGIONKEY
WHERE r.R_NAME = 'ASIA'
ORDER BY n.N_NAME;

What you should see: Five rows: the nations that belong to the ASIA region (CHINA, INDIA, INDONESIA, JAPAN, VIETNAM). This extends the join pattern from Step 5 by joining two small dimension tables and filtering on a value from one of them.

Task 4 - Total spend by market segment

SELECT
    c.C_MKTSEGMENT,
    ROUND(SUM(o.O_TOTALPRICE)) AS TOTAL_SPEND
FROM SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.CUSTOMER c
JOIN SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.ORDERS o
    ON c.C_CUSTKEY = o.O_CUSTKEY
GROUP BY c.C_MKTSEGMENT
ORDER BY TOTAL_SPEND DESC;

What you should see: Five rows, one per market segment, each with the summed order value across all customers in that segment, largest total first. The totals are large numbers in the hundreds of billions, because this sums 1.5 million order values. This query combines the join from Step 5 with the SUM and ROUND aggregation from the same step.

Task 5 - Highest value orders for a single segment

SELECT
    c.C_NAME,
    o.O_ORDERDATE,
    o.O_TOTALPRICE
FROM SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.CUSTOMER c
JOIN SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.ORDERS o
    ON c.C_CUSTKEY = o.O_CUSTKEY
WHERE c.C_MKTSEGMENT = 'AUTOMOBILE'
ORDER BY o.O_TOTALPRICE DESC
LIMIT 10;

What you should see: Ten rows: the highest value orders placed by customers whose market segment is AUTOMOBILE, ordered from the largest order total down. The O_TOTALPRICE values at the top should exceed 500,000. This extends the Step 5 join by adding a WHERE filter to restrict the rows before sorting and limiting.
